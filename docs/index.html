Powerful Features, Maximum Privacy

Designed for direct, zero-trust communication across your trusted subnets.

🔒

End-to-End Encryption

Powered by X25519 key exchange, AES-GCM encryption, and hash ratchets. Every frame is authenticated with Ed25519 signatures.

⚡

Automatic Peer Discovery

Zero configuration needed. Discover active peers instantly via UDP broadcast packets inside your local area network.

💻

Sleek TUI Interface

Lightning-fast Terminal User Interface built with Textual, featuring live presence monitoring, typing indicators, and desktop notifications.

Robust Local Security Architecture

  • ✓ Argon2id Vault: Local databases and master keys are strongly encrypted and protected behind a secure PIN code.
  • ✓ HMAC Audit Logs: Security events and actions are cryptographically chained to maintain tamper evidence.
  • ✓ Safety Numbers: Manually compare safety fingerprints to prevent man-in-the-middle attacks.
