Features

Built for people who take privacy seriously.

Every packet on the wire is authenticated, padded, and ratcheted. No telemetry. No phone home. Just peers on your subnet.

End-to-End Encrypted

X25519 ephemeral key exchange with per-session hash ratchets. Every message gets a fresh AES-GCM key. 256-byte padding on every payload.

Automatic Peer Discovery

Zero-config UDP broadcast discovery on port 50505. Peers appear automatically on your LAN, or add them by IP and TOTP code.

Beautiful TUI

A blazing-fast Terminal UI built on Textual. Live presence dots, typing indicators, notifications, message search, and full keyboard control.

Identity Verification

Fingerprint-based safety numbers let you verify contacts out-of-band. Mark contacts verified and enforce verified-only mode across the app.

Tamper-Evident Audit Log

Every security event is appended to an HMAC-chained log with a genesis anchor. Silent tampering becomes mathematically detectable.

PIN Lockout & Vault

Master key wrapped with Argon2id(PIN). Escalating lockouts after 5, 10, 20, 50 failures — up to a full day. No cloud recovery, by design.

Security

Every layer auditable.
Every byte defended.

LANMess is built from primitives you can inspect. There is no black box, no remote relay, and no hidden telemetry channel.

  • Argon2id Vault: 64 MB memory, 3 passes, 4 lanes. Your PIN never leaves the device.
  • Ed25519 signatures on every frame, including control traffic — not just messages.
  • Replay protection: 60-second time window + monotonic per-chain counters.
  • Secure delete PRAGMA + zeroed key buffers on lock / shutdown.
